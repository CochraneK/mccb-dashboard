# MCCB 认知测评工作台 · Demo（演示数据）

> **本站全部为合成演示数据**：13 个演示项目 / 346 名合成受试者（演示0001…）/ 约 700 次访视，
> 姓名、ID、分数均为程序生成（固定种子，可复现），**不含任何真实受试者信息**。
> 用于展示工作台的功能形态：图表、分组对比、显著性标注、项目/个人深链。

MCCB（MATRICS Consensus Cognitive Battery）神经认知测评的**自包含、零联网** HTML 工作台：1 个总览页 + 13 个项目报告 + 1 个个人报告页。Chart.js 已内联，打开即用，无需网络、无需安装。

## 打开方式

- 总览入口：[`mccb_dashboard.html`](mccb_dashboard.html)（根路径会自动跳转）
- 每个项目报告：`reports/report_*.html`
- 个人报告深链：`person.html?person=<文件名>|<受试者ID>`（从明细表「查看」直接进入）
- 离线使用：下载 / 拷贝整个文件夹，双击 `mccb_dashboard.html` 即可，全部功能（图表、搜索、深链、返回）可用

## 结构

| 路径 | 说明 |
|---|---|
| `mccb_dashboard.html` | 总览工作台（KPI / 趋势 / 雷达 / 热图 / KW 显著性 / 明细） |
| `reports/report_*.html` | 13 个演示项目报告，含返回总览与个人深链 |
| `person.html` | 个人报告页，按 `?person=` 定位单人 |
| `index.html` | 根路径跳转页 |

## 演示数据口径

- 13 个演示项目 → 9 个诊断分组（健康对照 / 精分 / 抑郁 / 双相 / 强迫 / HDN / 神经调控 / 独立项目 / 其他）
- 346 名合成受试者，年龄 18–58，2019-11 ~ 2026-09
- 神经调控 / tDCS 演示组带纵向改善趋势，用于展示干预前后对比图
